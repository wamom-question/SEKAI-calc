# SEKAI-calc

Discord上でプロセカのリザルト画像を投稿すると、自動でスコア計算を行い結果を返信するBotです。

## 主な機能
- プロセカのリザルト画像を添付してBotをメンションすると、スコア・判定数を自動でOCR認識し、計算結果を返信します。
- メッセージ本文に「debug」と含めると、認識領域のデバッグ画像や詳細サマリーも返信します。
- サーバーID等の設定不要で、どのサーバーでも導入可能です。

## 使い方
1. Botをサーバーに招待し、必要な権限（メッセージ閲覧・送信、ファイル添付）を付与してください。
2. プロセカのリザルト画像を添付し、Botをメンションしてメッセージを送信してください。
3. Botが自動で画像を解析し、スコアや判定数を返信します。
4. デバッグ情報が欲しい場合は、メッセージ本文に「debug」と含めてください。

## Dockerでの実行方法
1. `docker-compose.yml` と `dockerfile` が同梱されています。
2. `.env` ファイルを作成し、`DISCORD_BOT_TOKEN=あなたのBotトークン` を記載してください。
3. 以下のコマンドでビルド＆起動できます。

```sh
docker compose up --build -d
```

4. 停止は以下で可能です。

```sh
docker compose down
```

## 必要な環境
- Docker（推奨）または Python 3.8以降
- 必要なパッケージは `requirements.txt` を参照し、`pip install -r requirements.txt` でインストールしてください。
- OpenCV, pytesseract, easyocr などが必要です。

## 環境変数
- `DISCORD_BOT_TOKEN` : Discord Botのトークン

## 注意事項
- 画像の内容や画質によっては正しく認識できない場合があります。
- 本Botは非公式のファンメイドツールです。
